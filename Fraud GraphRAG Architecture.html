Decisions to approve

The graph query agent writes graph queries.This answers questions that no fixed tool can. Plain code lets a query run only if it reads (Neo4j checks this too), has a row limit and a time limit. It changes CLAUDE.md rule 11.
Communities come from plain code.Our Neo4j is the Community edition, with no graph data science plugin. Plain Python groups the claims by strong links. The cheap model writes one cached report for each group.
Replies are short by default.The answer comes first, in a few lines, with the sources. The investigator can ask for more.
